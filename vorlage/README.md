# Hilfe zu diesem Buch

Die ganze Hilfe steht als Webseite mit Suchfunktion in **`hilfe.html`** (Doppelklick, öffnet im Browser).
Neu erzeugen und öffnen:  `sh build.sh hilfe`   (Windows: `build.bat hilfe`).

Sie entsteht aus `motor/HILFE.md` (kommt mit jedem Motor-Update), aus deinen eigenen Notizen in
`meine-hilfe.md` (freiwillig) und aus der Variablen-Datei dieses Buchs.

Das Wichtigste in Kürze:

```sh
sh sync.sh              # am Anfang und am Ende (mehrere Computer)
sh build.sh schnell     # beim Schreiben
sh build.sh final       # Druckfassung
sh neu.sh "Titel"       # neue Geschichte · sh neu.sh tabelle "Titel" = neue Tabelle
sh update.sh            # neuer Motor
```
